📱 Install on Android (APK & Offline App)

Android Ready

You can run Personal LifeOS as a standalone native-style Android app with 100% local offline storage in two ways:

1. Instant Android Install (No PC Required):

Transfer this HTML file to your Android phone, open it in Chrome or Brave, tap the ⋮ Menu → Add to Home screen / Install App. It launches full-screen from your app drawer completely offline.

2. Native Android APK Package:

Download the included Android Studio / Gradle APK project zip from the chat attachment to compile a signed LifeOS-debug.apk locally via ./gradlew assembleDebug or automatically via the included GitHub Actions workflow.
